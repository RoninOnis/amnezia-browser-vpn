- **Панель администратора**: свой сервер Amnezia из попапа — список устройств, выпуск и отзыв
  ключей, обходчик на UDP/443. После первой настройки работает ограниченный ключ: только
  управление ключами.
- **Первый запуск**: блок «С чего начать», кнопка «Добавить ключ `vpn://`», «Панель» помечена
  «необязательно» — вместо пустого экрана.
- **Хелпер**: принимает адрес, вставленный из браузера, `host:port` и пустой порт; ошибки
  по-русски вместо `bad json`; имя устройства из ответа сервера; IPv6; таймауты SSH.
- **Windows**: один `.cmd` без прав администратора, путь с кириллицей, ARM.
