**Тестовый релиз.** Не для раздачи: расширение в нём **не подписано Mozilla**. Firefox
поставит его только с выключенной проверкой подписей (`xpinstall.signatures.required = false`).

## Что внутри 0.3.7

**Панель администратора** (паритет с Amnezia через SSH, без их GPL-кода):

- подключение к своему серверу Amnezia по SSH: адрес, порт, пользователь, пароль один раз;
- после первой настройки работа идёт ограниченным ключом: только список устройств, выпуск и отзыв ключей — ни одна другая команда этим ключом не выполняется;
- список устройств с именами и адресами, выпуск нового ключа с готовой ссылкой `vpn://`, отзыв;
- установка обходчика блокировок на UDP/443 из панели (отдельное действие, нужен полный SSH);
- проверка версий аддона и помощника с обновлением помощника в один клик.

**Интерфейс:**

- новые иконки вкладок и шестерёнки (свои SVG, MIT);
- первый запуск: блок «С чего начать» из трёх шагов, явная кнопка «Добавить ключ `vpn://`», честная подпись вместо «нажмите, чтобы подключиться», когда подключаться некуда;
- «Панель» помечена «необязательно» и получила выход «у меня нет своего сервера»;
- подсказки на «Сайтах» больше не противоречат режиму списков;
- из интерфейса убран жаргон: «помощник» вместо «хелпер», «обход блокировок» вместо «спутник», MTU и SOCKS5 с пояснениями;
- «Этот сайт» больше не показывает UUID на служебных страницах.

**Хелпер:**

- спокойно принимает то, что люди реально вставляют: адрес со схемой и слэшем, `host:port`, пустой порт, порт строкой;
- понятные ошибки вместо `bad json` и `dial tcp: address 70000: invalid port`;
- адрес в форме подключения нормализуется и в попапе тоже, порт из строки переезжает в поле порта;
- имя устройства берётся из ответа сервера;
- таймауты SSH-сессий, обязательная сверка `SHA256SUMS`, PSK не покидает сервер;
- IPv6-адреса серверов больше не ломают подключение.

**Windows:** установка одним `.cmd`, манифест пишет сам помощник (кириллица в пути больше
не ломает native messaging), есть `uninstall-windows.cmd`, поддержана Windows on ARM.

## Как поставить (только для теста)

1. Скачать `amnezia-browser-vpn-0.3.7.xpi`.
2. В Firefox: `about:config` → `xpinstall.signatures.required` = **false**.
3. Перетащить `.xpi` в окно браузера и подтвердить установку.
4. Помощник: `install-linux.sh` или `install-windows.cmd` из ассетов этого релиза.

После проверки вернуть `xpinstall.signatures.required` в `true`.

## Известное

- Расширение подпишут в AMO отдельным шагом — этот релиз тестовый и подписи не содержит.
- Через SOCKS5 идёт только TCP: UDP-приложения браузера (кроме QUIC, который отключается сам) в туннель не пойдут.
- Ключи профилей хранятся в `storage.local` расширения в открытом виде, как и в клиенте Amnezia.
