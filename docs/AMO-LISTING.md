# Подача в каталог AMO — готовые поля

Копировать в форму `https://addons.mozilla.org/developers/addon/submit/distribution`.
Канал: **listed** (в каталоге). ID дополнения не меняем — `awgbv@0xoni.ru`, иначе отвалится
native messaging.

## Название

```
AWG Browser Tunnel
```

## Краткое описание (summary, ≤250 символов)

```
Туннель AmneziaWG только для трафика Firefox: остальная система идёт напрямую. Два списка сайтов — «через VPN» и «напрямую», плюс переключатель для текущей вкладки. Нужен бесплатный локальный хелпер.
```

## Описание

```markdown
VPN только для браузера: в туннель уходит трафик Firefox, всё остальное на компьютере продолжает
работать напрямую. Система не перенастраивается, маршруты не меняются, права администратора не нужны.

**Что умеет**

* Импорт подключения по ссылке `vpn://` из приложения Amnezia (протокол AmneziaWG:
  Jc/Jmin/Jmax, S1–S4, H1–H4, I1–I5 — обфускация поддерживается полностью).
* Разделение трафика по доменам, как в десктопном клиенте: два списка — «через VPN» и «напрямую».
  Пока список «через VPN» пуст, в туннель идёт всё, кроме второго списка; как только в нём
  появились записи — только они.
* Переключатель для текущей вкладки: авто / через VPN / напрямую, поверх списков.
* Несколько профилей подключения и выбор активного, статистика, состояние handshake.

**Что нужно для работы**

Одно дополнение не может поднять AmneziaWG: у WebExtensions нет ни UDP, ни криптостека. Поэтому
рядом работает маленький хелпер `awgbv` (Go, открытый код, ~7 МБ). Он держит туннель в user space
через amneziawg-go и отдаёт локальный SOCKS5 на 127.0.0.1 — без TUN, без root, без изменения
системных маршрутов.

Установка хелпера — одна команда, репозиторий и релизы:
https://github.com/RoninOnis/amnezia-browser-vpn

Linux:
    bash install-linux.sh

Windows (PowerShell, без прав администратора):
    powershell -ExecutionPolicy Bypass -File install-windows.ps1

После установки дополнение находит хелпер само (native messaging).

**Чего не делает**

* Не отправляет трафик через серверы автора — сервер только ваш.
* Не собирает статистику, не содержит аналитики и рекламы.
* Не работает с XRay/OpenVPN/Cloak-профилями Amnezia — только AmneziaWG.

**Лицензия** MIT. Политика конфиденциальности: см. ссылку в карточке.
```

## Заметки для ревьюера

Обязательно заполнить, иначе дополнение отклонят как «нерабочее»:

```
Это компаньон для локального хелпера: дополнение само не может поднять VPN, потому что WebExtensions
не дают доступа к UDP и не имеют криптостека. Без хелпера виден и работает весь интерфейс, но
подключение не устанавливается — попап покажет "хелпер не отвечает".

Как проверить функциональность:
1. Скачать хелпер из релизов: https://github.com/RoninOnis/amnezia-browser-vpn/releases
   (Linux: bash install-linux.sh; Windows: powershell -ExecutionPolicy Bypass -File install-windows.ps1)
   Скрипт не требует root, кладёт бинарь в профиль пользователя и пишет манифест native messaging.
2. Вставить в разделе «Серверы» любую ссылку vpn:// от собственного сервера Amnezia либо тестовый
   конфиг из репозитория (tests/ — синтетические данные, реальных ключей там нет).
3. На «Главной» нажать большую кнопку: состояние меняется на «Защищено», в статистике появляется
   трафик, текущий сайт при добавлении в список «через VPN» начинает открываться через туннель
   (проверяется любым сервисом определения IP), а не попавший в списки — напрямую.

Разрешения обоснованы:
- proxy — собственно маршрутизация запроса в локальный SOCKS5 или напрямую;
- host_permissions <all_urls> — требование API: фильтр proxy.onRequest не вызывается для хостов,
  которых нет в host permissions, разделение трафика без этого не работает;
- nativeMessaging — управление локальным хелпером;
- tabs — переключатель режима для открытой вкладки;
- storage — профили и списки; alarms — периодическая проверка состояния туннеля.

Код полностью открыт (MIT): https://github.com/RoninOnis/amnezia-browser-vpn
Сетевых запросов к серверам автора нет: единственный адресат трафика — VPN-сервер пользователя.
```
