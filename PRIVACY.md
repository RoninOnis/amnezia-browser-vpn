# Политика конфиденциальности — AWG Browser Tunnel

Дополнение не собирает, не передаёт и не продаёт никаких данных. Ни телеметрии, ни аналитики,
ни рекламы, ни внешних серверов у проекта нет.

## Что хранится локально

В `storage.local` браузера, только на вашем компьютере:

* профили подключения, импортированные из ссылок `vpn://` (включая ключи AmneziaWG);
* списки сайтов «через VPN» и «напрямую»;
* настройки: автоподключение, порт локального прокси, идентификатор активного профиля.

Эти данные не покидают машину. Удалить их можно вместе с дополнением.

## Куда идёт трафик

* Сайты, попадающие под правила туннеля, идут через локальный прокси (127.0.0.1), который поднимает
  установленный вами хелпер `awgbv`. Хелпер шифрует трафик и отправляет его на **ваш собственный
  VPN-сервер** (Amnezia/WireGuard) — адрес задаёте вы сами в профиле подключения.
* Остальные сайты запрашиваются напрямую, как обычно.
* Автор дополнения не видит ни ваш трафик, ни список посещаемых сайтов: у него нет ни серверов,
  ни точек сбора.

## Разрешения и зачем они

| Разрешение | Зачем |
|---|---|
| `proxy` | Направить запрос в локальный прокси или напрямую |
| `host_permissions` (`<all_urls>`) | Техническое требование API: без него фильтр `proxy.onRequest` не получает запросы вообще и разделение трафика не работает |
| `nativeMessaging` | Связь с локальным хелпером `awgbv`, который держит туннель |
| `tabs` | Переключатель «Авто / Через VPN / Напрямую» для текущей вкладки |
| `storage` | Хранение профилей, списков и настроек |
| `alarms` | Периодическая проверка состояния туннеля при автоподключении |

## Сторонние сервисы

Нет. Дополнение не обращается ни к каким API, кроме вашего VPN-сервера через хелпер.
