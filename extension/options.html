Amnezia Browser VPN

Туннель AmneziaWG только для трафика Firefox. Остальная система ходит напрямую.

Профили подключения

Разделение трафика

Поддерживаются example.com (включая поддомены) и *.example.com. Списки сравниваются по имени хоста, IP тоже можно.

Поведение

Хелпер всегда слушает только 127.0.0.1. Смена порта применяется после переподключения.

Состояние

—

Как это работает

Расширение поднимает через локальный хелпер userspace-клиент AmneziaWG (без TUN, без прав администратора). Хелпер отдаёт SOCKS5 на 127.0.0.1, а расширение решает для каждого запроса, идти ему в туннель или напрямую. Остальная система при этом не затрагивается: системный маршрут по умолчанию не меняется.

Ключи профилей хранятся в хранилище расширения (storage.local) в открытом виде — как и в десктопном клиенте Amnezia.
